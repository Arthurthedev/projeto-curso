# Advice Generator App

## Sobre o Projeto

Este projeto é um desafio prático de desenvolvimento frontend inspirado em uma interface de página de música da plataforma Alura. 

Como o desenvolvimento foi guiado apenas por uma imagem estática de referência (sem acesso a arquivos de design originais ou especificações de layout como Figma), o projeto exigiu grande capacidade de adaptação para estimar proporções, buscar recursos visuais por conta própria e estruturar o layout de forma independente.

## Principais Desafios & Aprendizados

* **Primeiro contato com CSS Grid:** Por ser um dos primeiros projetos utilizando estruturação em Grid, precisei iterar e refazer o layout diversas vezes até compreender o posicionamento correto dos elementos.
* **Desenvolvimento sem Figma:** A ausência de medidas e assets originais treinou a minha percepção visual para aproximar o design de forma fiel e autônoma.
* **Responsividade:** Adaptação da interface para garantir um bom funcionamento em diferentes tamanhos de tela.
